# Agent Skills

Source repository for **aipartner** — a spec-driven workflow for Agent built around a
conversation instead of a form.

The whole thing is five skills. There are no scripts, no installer, and nothing to configure.

## Install

Copy the `aipartner-*` folders from `skills/` into `.claude/skills/` in your own project:

| Skill | Command |
|---|---|
| `aipartner-initial` | `/aipartner-initial` — scan the project, record how it is built |
| `aipartner-talk` | `/aipartner-talk` — discuss a feature, implement nothing |
| `aipartner-spec` | `/aipartner-spec` — turn the discussion into a plan and agent artifacts |
| `aipartner-execute` | `/aipartner-execute` — work through the task list |
| `aipartner-fix` | `/aipartner-fix` — correct something afterwards, and log it |

Each skill carries the templates it needs in its own `templates/` folder and creates whatever
directories it writes to. `/aipartner-initial` also drops a user-facing `README.md` into
`.aipartner/`, so the workflow documents itself in the target project.

## Layout

```text
skills/
├── aipartner-initial/    SKILL.md + templates/ (project-standards, README)
├── aipartner-talk/       SKILL.md + templates/ (talk-notes)
├── aipartner-spec/       SKILL.md + templates/ (plan, spec, tasks)
├── aipartner-fix/        SKILL.md + templates/ (fixes)
└── aipartner-execute/    SKILL.md
```

`.aipartner/` and `specs/` are generated by the commands. Nothing in this repo needs to be
created by hand.
